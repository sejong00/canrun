Kolibri 1 is a mixture-of-experts reasoning model that Aleph Alpha released in October 2026, focused on German and English. About 3.46B of its 78.1B parameters are active per token, and it takes text input only. Its model card lists multi-step reasoning, retrieval-augmented generation, agentic tool calling and coding. Thinking is on by default and can be switched off with `enable_thinking=false`; the native context is 262,144 tokens, and the Apache 2.0 license allows commercial use.
