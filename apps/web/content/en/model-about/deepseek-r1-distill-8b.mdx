DeepSeek R1 Distill Llama 8B is a reasoning model that DeepSeek released in January 2025. DeepSeek built it by fine-tuning Llama 3.1 8B on samples generated by DeepSeek-R1, targeting math, code and step-by-step reasoning. DeepSeek's weights are MIT-licensed, but the model card notes that the Llama 3.1 8B base it builds on is under the Llama 3.1 license.
