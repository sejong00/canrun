Gemma 4 31B is the largest model in Google DeepMind's Gemma 4 family, released in April 2026. It is a dense model that reads text and images with up to a 256k context, built for reasoning, coding and agent work with native function calling. Its thinking mode is off by default, and unlike Gemma 3 it is licensed under Apache 2.0.
