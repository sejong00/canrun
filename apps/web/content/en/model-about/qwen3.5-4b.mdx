Qwen3.5 4B is one of the small Qwen3.5 models that the Qwen team released in March 2026. It reads images and video as well as text, and it thinks before answering by default unless `enable_thinking` is set to false. Its model card highlights coding, agents, tool calling and 201 languages and dialects; the Apache 2.0 license allows commercial use. Only one layer in four uses full attention, which shrinks its KV cache to about a quarter.
