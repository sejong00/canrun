DeepSeek R1 Distill Qwen 14B is a reasoning model that DeepSeek released in January 2025, between the 8B and 32B distills of the same release. DeepSeek fine-tuned Qwen2.5-14B on samples generated by DeepSeek-R1 for math, code and step-by-step reasoning. The model card recommends a temperature of 0.5 to 0.7 and putting every instruction in the user message instead of a system prompt.
