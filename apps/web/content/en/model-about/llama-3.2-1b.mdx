Llama 3.2 1B is the smallest instruction-tuned text model in Meta's September 2024 Llama 3.2 release. Its model card names uses such as assistant-style chat, knowledge retrieval, summarization and prompt rewriting, and Meta expects it to run in constrained environments like mobile devices. It supports a 128k context and eight official languages, and services with more than 700 million monthly active users must request a separate license.
