DeepSeek R1 Distill Qwen 32B is a reasoning model that DeepSeek released in January 2025. DeepSeek built it by fine-tuning Qwen2.5-32B on samples generated by DeepSeek-R1, targeting math, code and step-by-step reasoning. The model card recommends a temperature around 0.6 and no system prompt, with every instruction in the user message.
