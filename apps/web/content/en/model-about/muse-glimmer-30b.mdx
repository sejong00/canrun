Muse Glimmer 30B is a dense model that Meta released in August 2026, distilled from Muse Spark for agent work on consumer hardware. It reads text and images, and its model card lists local and coding agents, tool calling and reasoning over screenshots, charts and documents. Thinking cannot be switched off; only its strength can be set, from low to xhigh, with high as the default. The context is 131,072 tokens, and the Apache 2.0 license allows commercial use.
