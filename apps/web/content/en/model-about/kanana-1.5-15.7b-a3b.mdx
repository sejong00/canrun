Kanana 1.5 15.7B-A3B is Kakao's first mixture-of-experts model, released in July 2025 for Korean and English. Kakao says it performs comparably to the dense Kanana 1.5 8B while using 37% of that model's compute per token, since only part of its 15.7B parameters is active for each token. Its Kanana License requires a separate commercial license for uses such as reselling API access.
