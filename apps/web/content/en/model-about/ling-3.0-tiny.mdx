Ling-3.0 Tiny is a small mixture-of-experts model that inclusionAI, Ant Group's AGI initiative, released in August 2026. It has 7.9B parameters in total, activates 1.3B per token and is built for local use, covering agent tasks, coding, math and science reasoning. Thinking is on by default and can be turned off per request, and the license is MIT.
