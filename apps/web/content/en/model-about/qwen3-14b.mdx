Qwen3 14B is the second-largest dense model in the Qwen3 family, which Alibaba Cloud's Qwen team released in April 2025. It thinks before answering by default, and adding `/no_think` to a message makes it reply directly instead. The model card highlights reasoning, coding, multilingual instruction following and tool use for agents.
