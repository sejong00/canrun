Qwen3 8B is a dense model that Alibaba Cloud's Qwen team released in April 2025. By default it thinks through math, coding and logic problems step by step, and the same model can switch thinking off for quick everyday chat. Its model card lists more than 100 languages and tool calling for agent tasks, and the Apache 2.0 license allows commercial use.
