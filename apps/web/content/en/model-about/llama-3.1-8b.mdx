Llama 3.1 8B is an instruction-tuned text model Meta released in July 2024 for assistant-style chat. Its model card lists eight supported languages (English, German, French, Italian, Portuguese, Hindi, Spanish and Thai), a 128k context and support for several tool use formats. The Llama 3.1 Community License allows commercial use, but services that had more than 700 million monthly active users when Llama 3.1 came out must request a separate license from Meta.
