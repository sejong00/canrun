gpt-oss-20b is an open-weight reasoning model that OpenAI released in August 2025. Its model card aims it at local and lower-latency use, with adjustable reasoning effort and built-in function calling, web browsing and Python code execution. It is a mixture-of-experts model with 3.6B of its 21B parameters active per token, released under the Apache 2.0 license.
