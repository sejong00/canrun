Llama 3.3 70B is an instruction-tuned text model Meta released in December 2024 for multilingual chat, meant for both commercial and research use. Its model card lists the same eight supported languages as Llama 3.1, a 128k context and tool use support. Under the Llama 3.3 Community License, services that had more than 700 million monthly active users when Llama 3.3 came out must request a separate license from Meta.
