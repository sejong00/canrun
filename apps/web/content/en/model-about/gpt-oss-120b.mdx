gpt-oss-120b is the larger of the two open-weight reasoning models OpenAI released in August 2025. Its model card aims it at general-purpose, high-reasoning work, with adjustable reasoning effort and built-in function calling, web browsing and Python code execution. It is a mixture-of-experts model with 5.1B of its 117B parameters active per token, released under the Apache 2.0 license.
