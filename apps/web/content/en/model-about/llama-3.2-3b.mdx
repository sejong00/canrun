Llama 3.2 3B is a small instruction-tuned text model Meta released in September 2024. Meta built it for multilingual chat and agent tasks such as knowledge retrieval and summarization, with constrained environments like mobile devices in mind. It supports a 128k context and eight official languages, and services with more than 700 million monthly active users must request a separate license from Meta.
