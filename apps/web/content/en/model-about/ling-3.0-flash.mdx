Ling-3.0 Flash is the larger sibling of Ling-3.0 Tiny, released in August 2026 by inclusionAI, Ant Group's AGI initiative. This mixture-of-experts model activates 5.1B parameters per token and targets coding, agent workflows, reasoning and contexts up to 256k. Few weights work on each token, yet all of them must sit in VRAM or system RAM; thinking is on by default and the license is MIT.
