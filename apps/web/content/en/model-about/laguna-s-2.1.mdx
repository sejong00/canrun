Laguna S 2.1 is a mixture-of-experts model from Poolside, released in July 2026 and designed for agentic coding and long-horizon software work. It has about 118B parameters in total but roughly 8B active per token, a 1M-token context window, and a thinking mode that can be turned off per request. The OpenMDW-1.1 license allows commercial use.
