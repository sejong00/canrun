## What Ollama and LM Studio need to install

### Ollama

Ollama's Windows page asks for <RuntimeFact id="ollama-windows-req" />. It installs into your home folder without administrator rights. Models need disk space of their own, many gigabytes for large ones; to move them, set `OLLAMA_MODELS` under "Edit environment variables for your account".

Ollama's hardware support page asks for <RuntimeFact id="ollama-nvidia-req" />. The two pages give different minimum NVIDIA drivers. `nvidia-smi` shows yours; if it is older than either page asks, update it. The RTX 4060, RTX 3060, RTX 5060 Ti, RTX 3090 and RTX 5090 all appear in that page's compute capability table.

On a Mac, Ollama needs <RuntimeFact id="ollama-macos-req" />. None of these requirement sections lists a RAM or VRAM minimum. Ollama's quickstart recommends VRAM only for its example model, Gemma 4 E2B, and adds that with less VRAM Ollama can use system RAM but may answer more slowly. In CanRun's calculation, E2B at Q4_K_M fits fully on an 8GB card such as the RTX 4060.<Expect model="gemma-4-e2b" gpu="rtx-4060" fits="true" mode="full-gpu" />

### LM Studio

For Windows PCs, LM Studio lists <RuntimeFact id="lmstudio-windows-req" />. AVX2 is required on x64, while the RAM and VRAM figures are recommendations, not minimums. It also runs on Windows on Arm (Snapdragon X Elite).

For Macs, it lists <RuntimeFact id="lmstudio-mac-req" />. So an Intel Mac can run Ollama, on the CPU only, but not LM Studio.

### AMD, Intel and Linux

Ollama runs supported Radeon cards through ROCm; its [hardware support page](https://docs.ollama.com/gpu) has separate Windows and Linux lists, and the Windows list is shorter. Other GPUs, AMD and Intel included, run through Vulkan, which is on by default and comes with most Windows drivers. For some RX 6000-series (RDNA2) systems that may not expose ROCm on current Windows drivers, the Windows page recommends Vulkan.

LM Studio has separate llama.cpp runtimes for CUDA, Vulkan, ROCm and the CPU, and Ctrl+Shift+R opens the screen where you pick one.

On Linux, Ollama installs with a script, and the CUDA and ROCm drivers are separate, optional installs. LM Studio ships as an AppImage for x64 and ARM64. For Radeon and Arc cards, see <GuideLink slug="amd-intel-gpus" />.
