## Power limits and heat: what CanRun does not calculate

The same laptop GPU does not get the same power in every laptop. NVIDIA's laptop comparison page gives each chip a range of GPU subsystem power instead of one figure. The range is 35 W to 115 W for the RTX 4060 Laptop and the RTX 4070 Laptop, 80 W to 150 W for the RTX 4090 Laptop and 95 W to 150 W for the RTX 5090 Laptop. Two laptops with the same GPU name can therefore run it at very different power. If the maker lists the GPU power in its spec sheet, note it when you compare laptops.

CanRun's calculation leaves power and heat out. Its speed estimate for a laptop chip uses the bandwidth on the spec sheet and the same efficiency factor as desktop NVIDIA cards. CanRun's data has no public benchmark of a laptop GPU yet. llama.cpp's public scoreboard for NVIDIA cards includes a few laptop results, but it does not record the power they ran at. How much speed a lower power limit or a hot chip costs is something CanRun has not measured, so read a laptop's speed band with more caution than a desktop card's.

Fit is a different matter. VRAM does not change with the power limit, so the memory results in this guide, which models fit and where the context runs out, hold for any laptop with that chip.

To learn what your own laptop does, measure it. <GuideLink slug="tokens-per-second" /> shows how to read the generation rate in Ollama, llama.cpp and LM Studio. If you use the laptop both plugged in and on battery, measure both ways. First make sure the model runs on the NVIDIA GPU at all: `ollama ps` should show `100% GPU` in the PROCESSOR column. <GuideLink slug="gpu-offload-check" /> covers what to check when it does not, including laptops with both integrated and discrete graphics.

## System RAM and MoE models

A mixture-of-experts (MoE) model splits most of each layer into expert blocks, and a router picks a few of them for each token. Each token reads only a small part of the weights, but the whole file has to be in memory. When it does not fit in VRAM, llama.cpp can keep the shared weights and as many experts as fit on the GPU and leave the rest in system RAM (`--n-cpu-moe`). ## How sure are these numbers?

The memory figures are calculated by formula from real GGUF file sizes, each file's header and each model's published configuration, so they carry no band. The laptop chips' VRAM comes from NVIDIA's specifications. It does not depend on the power limit, so the fit results apply to every laptop with that chip.

The speeds are estimates with a band and a label. Measured means a public benchmark for that card, model and quant; CanRun has none for laptop GPUs yet, so the laptop cells in this guide are estimates.<Expect model="llama-3.1-8b" gpu="rtx-4060-laptop" verdict="S" confidence="calibrated" /><Expect model="gpt-oss-20b" gpu="rtx-5090-laptop" verdict="S" confidence="calibrated" /> Calibrated means ±12% for dense models fully on an NVIDIA or AMD card and ±20% for MoE models, partial offload and other hardware. Theoretical means ±30%, for setups whose real speeds vary widely, such as MoE experts in system RAM. The bands for laptop chips assume the chip reaches its spec-sheet bandwidth and do not account for the power limit or heat, as the power section explains.

All verdicts assume Windows with the GPU also drawing the desktop, 32GB of DDR5-5600 dual-channel RAM, an 8k context, an f16 KV cache, one model loaded and one request at a time. Ollama and llama.cpp make their own memory estimates, so a model that only just fits here can end up partly in system RAM. `ollama ps` shows what happened on your laptop.

Models with a thinking mode face 1.5× stricter speed thresholds, which the legend does not show. In this guide that covers gpt-oss-20b and gpt-oss-120b, which always think, and Qwen3 14B, Qwen3.8 27B, Qwen3.5 35B-A3B and Nemotron 3.5 Lightning 30B-A3B, which can switch thinking on and off. EXAONE 4.0 32B has thinking off by default but is held to the same thresholds. Llama 3.1 8B and Gemma 3 12B have no thinking mode.
