## 수집하는 정보

- **회원가입, 로그인, 입력 양식이 없습니다.**
- **CanRun 자체는 쿠키를 쓰지 않습니다.** 방문 통계는 쿠키를 쓰지 않는 Cloudflare Web Analytics로만 봅니다(아래 ‘방문 통계’). 광고에 쓰이는 쿠키는 아래 ‘광고’에서 설명합니다.
- **계산은 브라우저 안에서 합니다.** 고른 GPU, 메모리, 설정은 내 기기에서 계산하고 저희에게 보내지 않습니다. 선택한 값은 즐겨찾기나 공유를 할 수 있게 페이지 주소에 들어갑니다. 그 주소를 다른 사람에게 보내면 받은 사람도 선택한 값을 볼 수 있습니다.
- **GPU 감지는 내 기기 안에서만 이뤄집니다.** 감지 버튼을 누르면 브라우저가 페이지에 어떤 그래픽 칩을 쓰는지 알려 줍니다. 이 확인은 브라우저 안에서만 하고 어디로도 보내지 않습니다.
- **목록에 없는 모델을 불러오면 브라우저가 Hugging Face에 직접 요청합니다.** 계산기에 모델 주소를 넣고 불러오기를 누르거나, 불러온 모델이 들어 있는 계산기 링크를 열면, 내 브라우저가 Hugging Face(huggingface.co)에 그 모델의 정보와 파일 목록을 요청합니다. 일부 모델(MoE 등)은 Hugging Face 다운로드 서버에서 모델 파일 앞부분 몇 MB를 함께 읽습니다. 이때 Hugging Face는 IP 주소 같은 요청 정보를 [Hugging Face 개인정보처리방침](https://huggingface.co/privacy)에 따라 처리합니다. 이 요청은 CanRun 서버를 거치지 않고, 저희는 어떤 모델을 불러왔는지 알 수 없습니다. 모델을 불러오지 않고 그런 링크도 열지 않으면 Hugging Face로 아무것도 요청하지 않습니다.

## 호스팅

사이트는 Cloudflare Pages로 제공합니다. 페이지를 전달하고 사이트를 악용에서 보호하기 위해 Cloudflare가 요청마다 IP 주소, 브라우저 종류 같은 기술 정보를 처리하며, 이는 [Cloudflare 개인정보처리방침](https://www.cloudflare.com/ko-kr/privacypolicy/)을 따릅니다. 저희가 이 정보로 방문자 목록을 받지는 않습니다.

## 방문 통계

어떤 페이지가 많이 읽히는지, 방문자가 어디에서 들어오는지 알기 위해 Cloudflare Web Analytics를 씁니다. 페이지를 열면 브라우저가 Cloudflare에 아래 정보를 보냅니다.

- 지금 보는 페이지 주소, 그리고 다른 사이트의 링크를 눌러 들어왔다면 그 사이트 주소
- 국가, 브라우저, 운영체제, 기기 종류(데스크톱·휴대폰·태블릿)
- 페이지가 열리는 데 걸린 시간 같은 속도 정보

이 통계는 쿠키나 브라우저 저장소를 쓰지 않고, Cloudflare는 IP 주소나 브라우저 정보로 개인을 구별하지 않습니다([Cloudflare Web Analytics 안내](https://www.cloudflare.com/web-analytics/)). 저희가 보는 것은 페이지별·국가별 방문 수 같은 합계뿐이라, 누가 어떤 페이지를 봤는지는 알 수 없습니다. 광고 차단기나 브라우저 설정으로 통계 스크립트(static.cloudflareinsights.com)를 막아도 사이트는 똑같이 쓸 수 있습니다.

## 광고

이 사이트의 광고는 Google 애드센스로 게재합니다. 광고가 표시되면 다음과 같이 쿠키가 쓰일 수 있습니다.

- Google을 비롯한 제3자 광고 업체는 쿠키를 사용해, 이용자가 이 사이트나 다른 사이트를 전에 방문한 기록을 바탕으로 광고를 게재합니다.
- Google은 광고 쿠키를 사용해, 이 사이트나 인터넷의 다른 사이트 방문 기록을 바탕으로 Google과 파트너가 이용자에게 광고를 게재할 수 있게 합니다.
- 맞춤 광고는 [Google 광고 설정](https://adssettings.google.com)에서 끌 수 있습니다. 제3자 업체의 맞춤 광고 쿠키는 [aboutads.info](https://www.aboutads.info/choices/)에서 거부할 수 있습니다.
- Google이 파트너 사이트에서 얻은 정보를 어떻게 쓰는지는 [Google 안내 페이지](https://policies.google.com/technologies/partner-sites)에 나와 있습니다.
