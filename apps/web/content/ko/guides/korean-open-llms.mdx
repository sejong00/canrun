Solar Open 100B 칸이 64GB 구성인 것은 어느 구성에서도 Q4_K_M이 들어가지 않기 때문이고<Expect model="solar-open-100b" gpu="apple-m4-pro" verdict="F" fits="false" />, IQ4_XS로 낮추면 겨우 가능이라는 힌트가 붙습니다. CanRun 계산으로는 CPU 전용 경로라 이론 추정입니다.

카드별 전체 결과는 <HubLink gpu="rtx-4060" />, <HubLink gpu="rtx-3060-12gb" />, <HubLink gpu="rtx-5060-ti-16gb" />, <HubLink gpu="rtx-3090" />, <HubLink gpu="rtx-5090" />, <HubLink gpu="apple-m4-pro" /> 페이지에 있습니다.

## 조금 넘칠 때 — 양자화, 시스템 RAM, 전문가 오프로드

양자화를 한 단계 낮추면 RTX 3060 12GB의 Kanana 1.5 15.7B-A3B는 GPU에 다 올라가지만, RTX 5060 Ti 16GB의 EXAONE 4.5 33B는 그렇지 않습니다. Solar Open 100B의 관건은 시스템 RAM입니다.

### Kanana 1.5 15.7B-A3B와 12GB 카드

RTX 3060 12GB에서 Q4_K_M은 <Num kind="needGB" model="kanana-1.5-15.7b-a3b" />로 사용 가능 메모리 <Num kind="usableGB" gpu="rtx-3060-12gb" />를 넘습니다. CanRun 계산은 이때 전문가를 시스템 RAM에 두고(MoE 전문가 RAM 배치) 겨우 가능(이론 추정)으로 판정합니다<Expect model="kanana-1.5-15.7b-a3b" gpu="rtx-3060-12gb" verdict="B" />. IQ4_XS는 <Num kind="needGB" model="kanana-1.5-15.7b-a3b" quant="IQ4_XS" />로 GPU에 다 올라가 쾌적(보정된 추정)이고, 품질 등급도 Q4_K_M과 같은 균형입니다. 여유가 넉넉하지 않으니 `ollama ps`로 확인하세요. Q2_K 행도 쾌적이지만 손실 큼 등급이라 권하지 않습니다(‘<GuideLink slug="gguf-quantization" />’ 참고).

<QuantLadder model="kanana-1.5-15.7b-a3b" gpu="rtx-3060-12gb" />

### EXAONE 4.5 33B와 16GB 카드

RTX 5060 Ti 16GB에서 EXAONE 4.5 33B의 Q4_K_M은 부분 오프로드로 겨우 가능(보정된 추정)입니다<Expect model="exaone-4.5-33b" gpu="rtx-5060-ti-16gb" verdict="B" />. IQ4_XS도 <Num kind="needGB" model="exaone-4.5-33b" quant="IQ4_XS" />로 사용 가능 메모리 <Num kind="usableGB" gpu="rtx-5060-ti-16gb" />를 넘어 부분 오프로드에 머물고, Q6_K·Q8_0은 불가입니다. EXAONE 4.0 32B도 IQ4_XS에 <Num kind="needGB" model="exaone-4.0-32b" quant="IQ4_XS" />가 필요하므로, 32B급 EXAONE은 양자화를 낮추기보다 메모리 24GB급 카드를 목표로 잡는 편이 맞습니다.

<QuantLadder model="exaone-4.5-33b" gpu="rtx-5060-ti-16gb" />

### Solar Open 100B와 전문가 오프로드

Solar Open 100B는 Q4_K_M·8k에서 <Num kind="needGB" model="solar-open-100b" />가 필요합니다. 판정 표의 MoE 모델(Kanana 1.5 15.7B-A3B·Solar Open 100B)은 GPU에 다 올라가지 않으면 CanRun 계산에서 전문가 가중치를 전부 시스템 RAM에, 나머지를 GPU에 둡니다. 그래서 시스템 RAM 32GB로는 표의 그래픽카드에 어떤 양자화도 들어가지 않고<Expect model="solar-open-100b" gpu="rtx-3090" verdict="F" fits="false" />, 64GB라면 겨우 가능입니다. 이 값은 이론 추정이며 보수적일 가능성이 큽니다(자세한 결과는 <HubLink model="solar-open-100b" /> 페이지). 전문가를 GPU와 RAM에 나눠 두는 경우는 계산하지 않습니다. llama.cpp 서버 README에 따르면 `--cpu-moe`는 MoE 가중치를 전부, `--n-cpu-moe N`은 앞쪽 N개 층의 것만 CPU에 둡니다. Ollama FAQ에는 이런 전문가 배치 옵션이 나오지 않습니다.

### 실행 명령 (Windows 먼저)

<RuntimeFact id="ollama-default-ctx" />. 그래서 8k는 직접 지정합니다. RTX 3060 12GB의 Kanana 1.5 15.7B-A3B IQ4_XS라면 트레이의 Ollama 앱을 끄고 PowerShell에서 `$env:OLLAMA_CONTEXT_LENGTH="8192"; ollama serve`를 띄운 뒤, 다른 창에서 `ollama run hf.co/mradermacher/kanana-1.5-15.7b-a3b-instruct-GGUF:IQ4_XS`를 실행합니다(Hugging Face 문서). macOS·Linux는 `OLLAMA_CONTEXT_LENGTH=8192 ollama serve`이고, Windows에서 계속 쓰려면 ‘계정의 환경 변수 편집’에 이 변수를 추가한 뒤(관리자 권한 불필요) Ollama를 다시 실행합니다. llama.cpp는 `llama-server -hf mradermacher/kanana-1.5-15.7b-a3b-instruct-GGUF:IQ4_XS -c 8192 -ngl all -fa on`입니다.

EXAONE은 4.0과 4.5의 LG GGUF 카드에 각각 적힌 최소 llama.cpp 빌드 이상인지 먼저 확인하세요. Ollama에서 EXAONE이 로드되는지는 시험하지 않았으니 Ollama를 최신 버전으로 올린 뒤 실행해 보고, `ollama ps`로 GPU에 다 올라갔는지 확인하세요.

## 이 숫자는 얼마나 확실한가

보정에 쓰는 공개 실측 가운데 한국 모델을 잰 것은 아직 없어서, 이 글의 속도는 모두 추정입니다. 보정된 추정은 NVIDIA·AMD 그래픽카드에 dense 모델을 다 올릴 때 ±12%, MoE·부분 오프로드·맥에서는 ±20%이고, 이론 추정은 ±30%입니다. 이론 추정인 칸이 생기는 이유는 세 가지입니다.

- **HyperCLOVA X SEED Think 14B의 모든 칸**: 공식 llama.cpp의 지원이 확인되지 않았습니다.
- **RTX 4060·RTX 3060 12GB의 Kanana 1.5 15.7B-A3B, Solar Open 100B의 RAM 힌트**: 전문가 RAM 배치 경로는 검증 실측이 없고, CanRun이 속도를 낮게 계산하는 것으로 파악돼 보수적일 가능성이 큽니다.
- **M4 Pro의 CPU 전용 칸(24GB 구성 EXAONE 4.0 32B, 64GB 구성 Solar 힌트)**: 통합 메모리 기기의 CPU 경로가 검증되지 않았습니다.

판정 표 아래의 ‘보수적’ 주석은 두 번째 경우의 이야기로, HyperCLOVA X SEED Think 14B에는 해당하지 않습니다.

리즈닝 모델(EXAONE 4.0 32B·4.5 33B, HyperCLOVA X SEED Think 14B)은 답 앞에 생각 과정을 출력하므로 속도 기준을 1.5배 엄격하게 적용합니다(아래 기준표는 기본 기준). 그래서 RTX 4060의 EXAONE 4.0 32B는 Q4_K_M 추정 속도가 리즈닝 모델의 속도 하한에 조금 못 미쳐 불가이고<Expect model="exaone-4.0-32b" gpu="rtx-4060" verdict="F" fits="true" />, RTX 3060 12GB의 HyperCLOVA X SEED Think 14B는 쾌적이 아니라 원활(이론 추정)입니다<Expect model="hyperclovax-seed-think-14b" gpu="rtx-3060-12gb" verdict="A" />. 리즈닝 모드를 끄고 쓴다면(모델 카드 참고) 이 엄격한 기준은 필요 이상이라, 판정이 실제보다 낮게 나올 수 있습니다.

<Threshold />

메모리 수치는 공식으로 계산한 값입니다(파일은 Hugging Face의 실제 GGUF 크기, KV 캐시는 모델 config). 예외는 KV 계산에서 빼 둔 EXAONE 4.0 32B·4.5 33B의 슬라이딩 윈도 층 몫과, 역시 빼 둔 EXAONE 4.5의 비전 프로젝터입니다. 런타임 빌드별 지원과 Ollama의 실제 배치는 CanRun이 확인할 수 없으니, `ollama ps`의 PROCESSOR 열이 `100% GPU`인지 CPU/GPU 비율인지 보세요(Ollama FAQ).

## 자주 묻는 질문

### 한국 오픈 LLM을 돌리려면 메모리가 얼마나 필요한가요?

판정 표의 한국 모델 여덟 종은 Q4_K_M·8k 기준으로 EXAONE 4.0 1.2B의 <Num kind="needGB" model="exaone-4.0-1.2b" />부터 Solar Open 100B의 <Num kind="needGB" model="solar-open-100b" />까지 필요하고, Solar Open 2는 IQ4_XS로도 <Num kind="needGB" model="solar-open2-250b" />가 필요합니다. 이 값을 카드 상자에 적힌 용량이 아니라 사용 가능 메모리와 비교하세요(‘<GuideLink slug="vram-requirements" />’, ‘<GuideLink slug="mac-local-llm" />’).

### EXAONE·Kanana·HyperCLOVA X SEED·Solar를 상업적으로 써도 되나요?

모델마다 다릅니다. EXAONE 세 모델은 비상업 라이선스(EXAONE AI Model License 1.2 NC), Kanana 1.5 8B는 Apache-2.0이고, Kanana 1.5 15.7B-A3B·HyperCLOVA X SEED·Solar는 저마다 별도 약관이 있습니다. CanRun의 라이선스 배지는 법률 조언이 아니니, 상업적으로 쓰기 전에 모델 카드에 연결된 라이선스 원문을 읽으세요.

### 한국 모델은 Ollama와 llama.cpp에서 돌아가나요?

대부분은 llama.cpp 계열 도구용 GGUF 파일이 있어 돌려 볼 수 있지만, CanRun이 직접 시험하지는 않았습니다. 예외는 HyperCLOVA X SEED Think 14B입니다. GGUF 카드가 네이버 클라우드의 llama.cpp 포크를 쓰라고 안내하므로 공식 llama.cpp와 Ollama에서 돌아가는지는 확인되지 않았습니다. Solar Open 2도 커뮤니티 GGUF만 있고 선형 어텐션을 섞은 구조라, 런타임 지원을 따로 확인해야 합니다. EXAONE은 LG 공식 GGUF가 있고, 그 카드에 최소 llama.cpp 빌드가 적혀 있으니 먼저 그 이상으로 업데이트하세요.

### Kanana 1.5 15.7B-A3B는 16GB 카드에서 쾌적한데 EXAONE 4.0 32B는 왜 아닌가요?

메모리에 다 들어가느냐의 차이입니다. Kanana 1.5 15.7B-A3B는 8k에서 <Num kind="needGB" model="kanana-1.5-15.7b-a3b" />라 RTX 5060 Ti 16GB의 사용 가능 메모리 <Num kind="usableGB" gpu="rtx-5060-ti-16gb" /> 안에 들어가 쾌적(보정된 추정)입니다<Expect model="kanana-1.5-15.7b-a3b" gpu="rtx-5060-ti-16gb" verdict="S" />. EXAONE 4.0 32B는 <Num kind="needGB" model="exaone-4.0-32b" />가 필요해, CanRun 계산으로는 가중치 일부를 시스템 RAM에 두는 부분 오프로드로 겨우 가능(보정된 추정)입니다<Expect model="exaone-4.0-32b" gpu="rtx-5060-ti-16gb" verdict="B" />. MoE인 Kanana는 토큰마다 약 3B 파라미터만 계산해 GPU에 다 올라가면 빠르지만, dense 모델은 일부가 넘치면 느린 시스템 RAM 때문에 속도가 크게 떨어집니다.

### 내 PC에는 어떤 한국 모델을 고르면 되나요?

8k 필요 메모리가 카드의 사용 가능 메모리에 여유를 조금 두고 들어가는 가장 큰 모델을 고르고, 그다음 라이선스를 확인하세요. 12GB 카드와 16GB 카드에서는 Kanana 1.5 15.7B-A3B에 맞는 양자화가 다릅니다.

- **12GB(RTX 3060 12GB)**: Kanana 1.5 15.7B-A3B는 Q4_K_M 대신 IQ4_XS로 낮추면 GPU에 다 올라가 쾌적(보정된 추정)입니다.
- **16GB(RTX 5060 Ti 16GB)**: Kanana 1.5 15.7B-A3B는 Q4_K_M 그대로 쾌적(보정된 추정)입니다<Expect model="kanana-1.5-15.7b-a3b" gpu="rtx-5060-ti-16gb" verdict="S" />.
