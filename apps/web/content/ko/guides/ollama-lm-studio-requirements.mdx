## Ollama·LM Studio 설치 조건 — OS·CPU·GPU

### Ollama

Ollama의 Windows 요구 사항은 <RuntimeFact id="ollama-windows-req" />입니다. 관리자 권한 없이 홈 폴더에 설치되고, 모델 파일은 크기만큼 디스크를 따로 차지합니다. 모델 폴더는 ‘계정의 환경 변수 편집’에서 `OLLAMA_MODELS`로 옮깁니다.

하드웨어 지원 문서는 <RuntimeFact id="ollama-nvidia-req" />을 요구합니다. 두 문서의 NVIDIA 드라이버 하한은 서로 다릅니다. `nvidia-smi`로 본 버전이 어느 한쪽보다 낮으면 업데이트합니다. RTX 4060·3060·5060 Ti·3090·5090은 모두 이 문서의 Compute Capability 표에 있습니다.

맥에서 Ollama를 쓰는 조건은 <RuntimeFact id="ollama-macos-req" />입니다. Ollama 요구 사항 어디에도 RAM·VRAM 최소치는 없습니다. 빠른 시작 문서의 메모리 권장은 예제 모델 Gemma 4 E2B 기준입니다. VRAM이 모자라면 시스템 RAM을 쓰지만 답이 느려질 수 있다고도 적혀 있습니다. CanRun 계산으로는 E2B Q4_K_M이 메모리 16GB인 M4 맥에도 전부 들어갑니다<Expect model="gemma-4-e2b" gpu="apple-m4" ram="16" fits="true" mode="full-gpu" />.

### LM Studio

LM Studio의 Windows PC 조건은 <RuntimeFact id="lmstudio-windows-req" />입니다. x64 PC에서 AVX2는 필수이고, RAM·VRAM 수치는 최소가 아니라 권장값입니다. 맥용 조건은 <RuntimeFact id="lmstudio-mac-req" />입니다. Intel 맥에서 Ollama는 CPU만으로 돌아가지만, LM Studio는 지원하지 않습니다.

### AMD·인텔 그래픽카드와 리눅스

Ollama는 지원하는 라데온 카드를 ROCm으로 돌립니다. [하드웨어 지원 문서](https://docs.ollama.com/gpu)의 지원 카드 목록은 Windows용이 리눅스용보다 짧습니다. 그 밖의 GPU는 AMD·인텔을 포함해 기본으로 켜진 Vulkan으로 돌아갑니다. Windows 드라이버에는 대개 Vulkan이 들어 있습니다. RX 6000 시리즈(RDNA2) 일부는 지금 Windows 드라이버로 ROCm을 못 쓸 수 있습니다. 문서는 이때 Vulkan을 쓰라고 안내합니다.

LM Studio에는 CUDA·Vulkan·ROCm·CPU용 llama.cpp 런타임이 따로 있습니다. Ctrl+Shift+R로 여는 런타임 화면에서 고릅니다. 리눅스용 Ollama는 설치 스크립트를 제공하고, CUDA·ROCm 드라이버는 필요하면 따로 설치합니다. LM Studio는 x64·ARM64용 AppImage로 나옵니다. 라데온·인텔 카드는 ‘<GuideLink slug="amd-intel-gpus" />’ 가이드에서 다룹니다.

```powershell
ollama run hf.co/unsloth/Qwen3-8B-GGUF:Q4_K_M
ollama run hf.co/unsloth/Qwen3-14B-GGUF:Q4_K_M
ollama run hf.co/ggml-org/gpt-oss-20b-GGUF:MXFP4
ollama run hf.co/bartowski/Qwen_Qwen3.6-35B-A3B-GGUF:Q4_K_M
```

CanRun처럼 8k로 맞추려면 앱 설정의 컨텍스트 슬라이더를 옮깁니다. 아니면 작업 표시줄의 Ollama를 끄고 PowerShell에서 서버를 띄웁니다.

```powershell
$env:OLLAMA_CONTEXT_LENGTH="8192"; ollama serve
```

macOS·Linux에서는 이렇게 실행합니다.

```shell
OLLAMA_CONTEXT_LENGTH=8192 ollama serve
```

`ollama ps`에는 SIZE, PROCESSOR, CONTEXT 열이 나옵니다. PROCESSOR는 `100% GPU`, `100% CPU`, CPU/GPU 비율 중 하나입니다. 예상과 다른 비율이 나오면 ‘<GuideLink slug="gpu-offload-check" />’ 가이드를 봅니다.

## LM Studio에서 VRAM 맞추기 — 예상 메모리와 GPU 오프로드

LM Studio의 모델 검색(Ctrl+Shift+M)은 Hugging Face 저장소를 보여 줍니다. `unsloth/gemma-4-12b-it-GGUF`처럼 CanRun이 계산하는 GGUF를 그대로 받을 수 있습니다.

<QuantLadder model="gemma-4-12b" gpu="rtx-4060" />

RTX 4060에서 IQ4_XS는 아슬아슬하게 GPU에 다 올라가 원활하게 돌아갑니다<Expect model="gemma-4-12b" gpu="rtx-4060" quant="IQ4_XS" verdict="A" mode="full-gpu" />. Ollama에서는 아래처럼 받고 `ollama ps`로 확인합니다.

```powershell
ollama run hf.co/unsloth/gemma-4-12b-it-GGUF:IQ4_XS
```

UD-Q2_K_XL은 쾌적하게 돌아가지만<Expect model="gemma-4-12b" gpu="rtx-4060" quant="UD-Q2_K_XL" verdict="S" mode="full-gpu" /> ‘손실 큼’ 등급입니다. LM Studio 문서도 PC가 감당할 수 있다면 4비트 이상을 고르라고 권합니다. Q8_0은 일부가 RAM으로 가서 느리게 돌아갑니다<Expect model="gemma-4-12b" gpu="rtx-4060" quant="Q8_0" verdict="B" mode="partial-offload" />.

불러오기 화면에서 컨텍스트 길이와 GPU 오프로드 슬라이더를 옮기면 예상 메모리가 바로 바뀝니다. 메모리가 모자랄 것 같으면 불러오기 전에 경고가 뜨고, 무시하고 불러올 수도 있습니다. 명령줄에서는 아래처럼 예상치만 봅니다.

```powershell
lms load --estimate-only <model> --context-length 8192 --gpu max
```

`--gpu`는 `max`, `off`, 0에서 1 사이 값을 받고, 빼면 LM Studio가 스스로 정합니다. LM Studio에서는 CanRun 표보다 이 예상치가 더 맞는 기준입니다. 기본 컨텍스트는 문서에 없으니 8192로 맞춰 비교합니다.

## 그래픽카드가 없거나 맥을 쓴다면

CPU만 쓰면 모델 전체가 시스템 RAM에 올라갑니다. Qwen3 8B는 RAM 16GB에 들어가고<Expect model="qwen3-8b" gpu="cpu-ddr5-5600-2ch" ram="16" fits="true" mode="cpu-only" />, 듀얼 채널 DDR5-5600에서 겨우 돌아갑니다<Expect model="qwen3-8b" gpu="cpu-ddr5-5600-2ch" verdict="B" confidence="calibrated" />. CPU 전용 구성은 속도와 관계없이 이 단계가 상한입니다. gpt-oss-20b는 16GB로는 올릴 수 없고<Expect model="gpt-oss-20b" gpu="cpu-ddr5-5600-2ch" ram="16" fits="false" />, 32GB면 올라갑니다<Expect model="gpt-oss-20b" gpu="cpu-ddr5-5600-2ch" ram="32" fits="true" mode="cpu-only" />. ‘<GuideLink slug="cpu-only-llm" />’ 가이드에서 더 다룹니다.

맥에서 CanRun은 파일 전체를 필요량으로 보고, 통합 메모리의 약 70%를 GPU 몫으로 계산합니다. M4 16GB에서 Qwen3 8B는 GPU로 원활하게 돌아갑니다<Expect model="qwen3-8b" gpu="apple-m4" ram="16" verdict="A" mode="full-gpu" />. 맥에서 <Num kind="needGB" model="gpt-oss-20b" gpu="apple-m4" />가 필요한 gpt-oss-20b는 16GB로는 올릴 수 없고<Expect model="gpt-oss-20b" gpu="apple-m4" ram="16" fits="false" />, 24GB 구성이면 올라갑니다<Expect model="gpt-oss-20b" gpu="apple-m4" ram="24" fits="true" mode="full-gpu" />. 두 앱의 MLX 엔진은 CanRun 계산 밖입니다. 맥은 ‘<GuideLink slug="mac-local-llm" />’ 가이드에서 더 다룹니다.

## 이 숫자는 얼마나 확실한가

메모리 수치는 GGUF 파일과 모델 config로 공식에 따라 계산한 값입니다. ‘보정된 추정’ 속도는 NVIDIA·AMD 그래픽카드에 dense 모델을 다 올리면 ±12%입니다. MoE 모델, 부분 오프로드, 그 밖의 하드웨어는 ±20%입니다. 표의 8GB·12GB·16GB 카드에서 MoE 전문가를 RAM에 두는 칸은 모두 이론 추정(±30%)입니다. 표에서 실측 라벨은 16GB·24GB·32GB 카드의 gpt-oss-20b에 붙습니다<Expect model="gpt-oss-20b" gpu="rtx-5060-ti-16gb" confidence="measured" /><Expect model="gpt-oss-20b" gpu="rtx-3090" confidence="measured" /><Expect model="gpt-oss-20b" gpu="rtx-5090" confidence="measured" />. 24GB·32GB 카드의 Gemma 4 26B-A4B도 그렇습니다<Expect model="gemma-4-26b-a4b" gpu="rtx-3090" confidence="measured" /><Expect model="gemma-4-26b-a4b" gpu="rtx-5090" confidence="measured" />.

CanRun은 언어 모델 파일만 셉니다. gemma4·qwen3.6 태그의 비전 프로젝터와 draft 모델은 빠지고, Ollama 빌드도 CanRun 파일과 다릅니다. 실제 사용량은 `ollama ps`로 확인합니다. 계산은 그 카드로 Windows 화면을 출력하고, 시스템 RAM 32GB(DDR5)에 모델 하나·요청 하나를 가정합니다. 본문의 판정은 8k 컨텍스트, f16 KV 캐시 기준입니다. Qwen3 8B·14B와 Qwen3.6 35B-A3B는 생각 모드가 기본으로 켜져 있습니다. gpt-oss-20b는 생각 모드를 끌 수 없습니다. 그래서 이 모델들은 속도 기준이 1.5배 높습니다. Gemma 4는 생각 모드가 기본으로 꺼져 있습니다.

## 자주 묻는 질문

### Ollama 최소 사양은 어떻게 되나요?

Ollama 문서의 요구 사항은 OS와 GPU 드라이버 조건뿐이고, RAM·VRAM 최소치는 없습니다. 필요한 메모리는 올리는 모델이 정합니다. Qwen3 8B는 8GB 카드에 전부 올라가고<Expect model="qwen3-8b" gpu="rtx-4060" fits="true" mode="full-gpu" />, CPU로만 돌려도 RAM 16GB에 들어갑니다<Expect model="qwen3-8b" gpu="cpu-ddr5-5600-2ch" ram="16" fits="true" mode="cpu-only" />.

### VRAM 8GB로는 어떤 모델을 돌릴 수 있나요?

8GB 카드에는 Qwen3 8B가 GPU에 전부 올라가고, RTX 4060에서 쾌적하게 돌아갑니다<Expect model="qwen3-8b" gpu="rtx-4060" verdict="S" mode="full-gpu" />. 같은 카드에서 Gemma 4 12B는 일부가 RAM으로 가지만 원활하게 돌아갑니다<Expect model="gemma-4-12b" gpu="rtx-4060" verdict="A" mode="partial-offload" />. gpt-oss-20b는 전문가 일부를 RAM에 두면 올라갑니다<Expect model="gpt-oss-20b" gpu="rtx-4060" fits="true" mode="cpu-moe" />. 속도는 이론 추정이라 위 표에서 범위로 봅니다.

### LM Studio와 Ollama 중 사양이 더 낮은 쪽은 어디인가요?

같은 모델이라면 필요한 메모리는 같습니다. 두 앱 모두 llama.cpp로 GGUF를 돌려 가중치와 KV 캐시가 같은 양을 차지합니다. 차이는 플랫폼 조건과 기본값입니다. LM Studio는 x64 PC에서 AVX2가 필요하고 Intel 맥을 지원하지 않습니다. Ollama는 8GB·12GB·16GB 카드에서 4k로 시작합니다. 자세한 차이는 ‘<GuideLink slug="ollama-vs-llama-cpp-lm-studio" />’ 가이드에 있습니다.

### 시스템 RAM은 얼마나 있어야 하나요?

VRAM에 안 들어가는 부분과 OS 몫을 합친 만큼 있어야 하고, CanRun은 32GB로 계산합니다. 8GB 카드에서 gpt-oss-20b는 RAM 16GB로도 올라갑니다<Expect model="gpt-oss-20b" gpu="rtx-4060" ram="16" fits="true" mode="cpu-moe" />. Qwen3.6 35B-A3B는 16GB로는 올릴 수 없고<Expect model="qwen3.6-35b-a3b" gpu="rtx-4060" ram="16" fits="false" />, 32GB면 올라갑니다<Expect model="qwen3.6-35b-a3b" gpu="rtx-4060" ram="32" fits="true" mode="cpu-moe" />. 그래픽카드가 없으면 모델 전체가 RAM에 놓여, gpt-oss-20b도 16GB로는 모자라고<Expect model="gpt-oss-20b" gpu="cpu-ddr5-5600-2ch" ram="16" fits="false" /> 32GB면 들어갑니다<Expect model="gpt-oss-20b" gpu="cpu-ddr5-5600-2ch" ram="32" fits="true" mode="cpu-only" />.

### 한국어로 쓸 모델은 무엇을 받으면 되나요?

CanRun은 언어별 답변 품질을 평가하지 않아서, 한국어용 순위는 매기지 않고 올라가는지와 속도만 보여 줍니다. EXAONE·Kanana·HyperCLOVA X SEED 같은 한국 모델은 ‘<GuideLink slug="korean-open-llms" />’ 가이드에 `hf.co` 명령과 함께 있습니다. Kanana 1.5 8B는 RTX 4060에 1GB 안팎의 여유를 두고 전부 올라갑니다<Expect model="kanana-1.5-8b" gpu="rtx-4060" fits="true" mode="full-gpu" />.
