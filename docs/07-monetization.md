## 2. 페이지별 배치 맵
- **F 판정(못 돌림) 콤보** = 최고 전환 지면: ①"이 quant면 가능" 대안 ②업그레이드 최저가 GPU 2종(Amazon/쿠팡) ③**"지금 클라우드에서 시간당 $X로 실행" (RunPod 딥링크: 해당 모델 템플릿)** — 3열 카드.
- S/A 판정: 광고만(전환 의도 낮음). 허브: 하단 관련 GPU 가격 표. 가이드: 인콘텐츠 광고 + 문맥 어필리에이트.
- Build Advisor(P3): 목표(모델·tok/s) → 신품/중고/클라우드 3열 비용 비교 — canirunthisllm의 Build Advisor가 검증한 컨셉을 가격·중고 데이터로 상회.

## 3. 광고 UX 가드레일
페이지당 슬롯 ≤3(계산기 인터랙션 영역·판정 헤더 위 금지), 고정 높이 예약(CLS<0.1), 계산기 페이지는 결과 하단 1개만. 앵커/전면 광고는 Journey 전환 후 A/B로만.

## 4. 컴플라이언스 체크리스트
ads.txt / 어필리에이트 고지 문구(en·ko, FTC + 쿠팡 파트너스 필수 문구 "이 포스팅은 쿠팡 파트너스 활동의 일환으로…") / privacy policy에 AdSense·애널리틱스 쿠키 고지 / EEA 동의 모드(CF 존 설정 or CMP) / 가격 `priceAsOf` 표기(오도 방지).

민감도: US:KR 트래픽 비 6:4→8:2면 광고 +40%. 신모델 서지 달은 ±50% 변동. 어필리에이트는 Build Advisor(P3) 전까지 하단 밴드로 가정. **RunPod 열은 코호트 감쇠 반영값 — "최근 6개월 내 유입된 추천의 지출 × 10%"이며, 트래픽 성장이 멈추면 6개월 뒤 0으로 수렴한다고 가정하고 계획할 것.**
