# 06. 로드맵·태스크 분해 (Claude Code 세션 단위)

> 사용법: 각 태스크 = Claude Code 1세션 분량. 세션 시작 시 `CLAUDE.md` + 해당 참조 문서를 컨텍스트로. **완료 기준(AC) 전부 충족 전 다음 태스크 금지.** 기간은 부업 페이스(주 10~15h) 가정 — 풀타임이면 절반. 일정이 밀리면 **범위(에디토리얼 편수·생성 콤보 수)를 줄이고 게이트는 유지**한다.

## Phase 0 — 기반 (1~3주차)

**P0-1. 저장소 스캐폴드** — ref: `05-architecture.md` §1·2
모노레포(pnpm) + Next.js 15 static export + next-intl + Tailwind/shadcn + CI(typecheck·vitest·zod 검증·**gitleaks 시크릿 스캔**) + CF Pages 연결(토큰은 Actions Secrets만 — `05` §8).
AC: `pnpm build` 성공, en/ko 헬로 페이지 배포 + **i18n 스파이크: "en 루트 + `/ko/`" URL이 static export 산출물에서 실제 확인**(불가 시 폴백 결정 기록 — `05` §1) + `aliases.json→_redirects` 생성 스텁, CI 그린.

**P0-2. 계산 엔진 (TDD)** — ref: `02-engine-spec.md` 전체
constants(출처 주석) → memory → fit → speed → verdict. §8 테스트 케이스 먼저 작성.
AC: §7 검증 수치 재현(가중치 MAE<1%, 속도 12점 밴드 통과), 커버리지 90%+, 의존성 0.

**P0-3. 데이터 스키마·시드 v1** — ref: `03-data-spec.md` §1~4
zod 스키마 + 본 문서 표를 JSON화(GPU 42·모델 20·quant·실측 ~30점, sources 필수).
AC: 검증 통과, `모든 (GPU×모델×quant)` 엔진 스모크 실행 시 NaN/음수 0건.

**P0-4. HF 동기화 스크립트** — ref: `03` §5
sync-models(파일 크기·config) + new-model-alert + PR 자동화.
AC: 드라이런으로 시드 대비 diff 리포트 생성, 수동 실행 1회로 실데이터 검증.

**P0-4b. (병행, 사람 작업) 한국 모델 스펙 수집** — EXAONE 4.0/Kanana/HyperCLOVA X SEED config+GGUF 확인 → models.json 추가.
**P0-5. (병행, 사람 작업) 자체 실측 1차 — RTX 5060 Ti 16GB** — ref: `03` §6 프로토콜·매트릭스(A~D그룹). AC: benchmarks.json에 own 실측 ≥30행(A그룹만으로 충족 가능), gpt-oss-20b 공개 실측(111.6 tok/s) 대비 ±15% 내 재현 확인.

## Phase 1 — MVP 출시 (4~7주차)

**P1-1. 페이지 템플릿: 허브 2종** — ref: `01-prd.md` §2 F1/F2, `04` §4·5
GPU 허브·모델 허브 + verdict 카드/표 컴포넌트 + JSON-LD + hreflang.
AC: 대표 페이지 Lighthouse 90+, en/ko 대칭 hreflang 검증 통과(테스트로).

**P1-2. 콤보 페이지 템플릿** — 품질 요건 8요소 전부(`04` §4), 커맨드 스니펫 생성기(-ngl/--n-cpu-moe 계산), 인접 콤보 내부링크.
AC: "깊이 테스트" — 무작위 3페이지에서 GPU명 마스킹해도 수치로 구분 가능. noindex 로직(publishBatch) 동작.

**P1-3. 계산기·홈** — F4 + WebGPU 감지 + 공유 URL. AC: 모바일 실기기 테스트, 감지 실패 시 무소음 폴백.

**P1-4. 에디토리얼 — 출시 시 12편(en 6 + ko 6), 출시 후 4주 내 20편 도달** — ref: `04` §9 목록(상위 항목 우선). Claude 초안 → **사람 감수 필수**(특히 ko), 계산기 위젯 임베드.
AC: 각 편에 자체 데이터/실측 1개 이상 인용(외부 표 전재 금지). 감수가 병목이면 편수를 더 줄이되(최소 10) 출시일을 밀지 말 것.

**P1-5. 출시 배치 0** — about/privacy/contact·methodology(오차 공개), 사이트맵 분할, GSC+네이버 SA 등록, RSS.
AC: 라이브, 서치콘솔 2종 사이트맵 접수 확인. **← M1 마일스톤**

**P1-6. 배치 1 콤보 120p 공개** (+2주) → 4주 인덱싱 ≥80% 게이트 모니터링(주간 GSC 기록을 저장소에 커밋).

## Phase 1.5 — 수익 기반·확장 (7~10주차)
- AdSense 신청(에디토리얼+도구 상태에서 — 프로그래매틱 대량 공개 전) → 승인 후 ads.txt·슬롯 3개 한정(`07` §3). 
- 게이트 통과 시 배치 2(240p)→3(600p 전체). 신모델 48h 플레이북 1회 실전(다음 릴리스 대상).
- 네이버 블로그 개설·주 1회 연재 시작. Journey by Mediavine 신청(세션 1K 도달 시).
- KR 커뮤니티 소프트 런칭: 아카라이브 로컬 채널에 5060 Ti 16GB 실측 + 도구 소개(기여 톤 — 16GB 유저가 다수라 공감대 유리).

## Phase 2 — 커뮤니티 실측 (3~4개월차) — ref: `01` §4, `05` §4
P2-1 Workers+D1+제출 API+파서(AC: llama-bench 실출력 5종 파싱 통과) → P2-2 제출 UI+검수 큐 → P2-3 페이지 실측 표시·배지 전환 → P2-4 주간 보정 배치(effOverride) → P2-5 공개 Dataset 페이지(CC-BY) → (준비되면) Show HN / r/LocalLLaMA 공개 포스트("실측 N건으로 검증된 계산기, MAE 공개").
게이트: 월 제출 30건+ & 스팸 비율 통제 확인 후 리더보드.

## Phase 3 — 수익 고도화 (5~6개월차) — ref: `07`
Build Advisor(신품/중고/클라우드 3열) → RunPod·Amazon·쿠팡 링크 전면 적용 → 비교 페이지·임베드 배지 → (검토) 공개 API·Danawa 연동.
