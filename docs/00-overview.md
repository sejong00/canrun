# 00. 프로젝트 개요 — "내 PC로 돌릴 수 있을까?" (코드네임: CanRun)

> 작성일: 2026-08-09 · 작성: Claude (Fable) + YOO · 상태: **계획 확정, 구현 착수 대기**
> 이 문서 세트는 Claude Code / Codex에 그대로 투입하는 실행 명세입니다. 전체 요약은 이 문서, 상세는 01~07 참조.

## 1. 한 줄 정의

게임의 "Can You Run It"의 AI 모델 버전. 사용자가 GPU/RAM(또는 Mac/APU)을 입력하면 **어떤 오픈 LLM을 몇 quant로 돌릴 수 있는지 + 예상 tok/s**를, 모델을 입력하면 **최소/권장 하드웨어**를 보여주는 계산기 + 프로그래매틱 SEO 사이트.

## 2. 확정된 의사결정 (2026-08-09, YOO 승인)

| 항목 | 결정 | 근거 |
|---|---|---|
| 시장/언어 | **영어+한국어 동시 출시** (`/` en, `/ko/`) | 글로벌 검색량 + 한국어 시장은 네이티브 도구 전무(경쟁 조사 확인) |
| MVP 범위 | **계산기 + SEO 페이지** (DB 쓰기 없음, 정적) — 단, **풀 기능 확장을 전제로 설계** | 빠른 출시. 스키마/아키텍처는 Phase 2(벤치마크 제출)·Phase 3(어필리에이트)를 처음부터 수용 |
| 스택 | Next.js 15 static export + TypeScript + 순수 TS 계산 엔진 패키지 | 상세 `05-architecture.md` |
| 호스팅 | Cloudflare Pages (무료, 대역폭 무제한) | 비용 $0 시작 |
| 데이터 | 저장소 내 버전 관리 JSON (HF API 동기화 스크립트) | MVP에 DB 불필요 |

## 3. 왜 지금인가 (리서치 근거, 2026-08)

- **수요 성장 중**: Ollama 월 활성 개발자 890만, 2026-07 $65M 시리즈 B. r/LocalLLaMA 79.5만 명(+54.8% YoY). 구글 자동완성에 "can i run llama 70b locally", 한국어 "로컬 llm **사양**"이 상위 노출 = 상시 검색 수요.
- **경쟁 공백**: VRAM 계산기는 20개+ 난립(포화)이지만, ①실측 캘리브레이션된 속도 예측 ②커뮤니티 벤치마크 ③GPU×모델 SEO 페이지 ④구매/렌트 연결 — **4개를 다 하는 곳이 없음**. 한국어 네이티브 도구는 0개.
- **콘텐츠 구조적 증가**: 신규 GPU × 신규 모델 = 페이지 자동 증가. 신모델 출시 48시간 내 "hardware requirements" 페이지 = 반복 가능한 랜드그랩(apxml이 이 패턴으로 월 34.8만 방문 입증).
- **AI Overviews 방어**: 정보성 텍스트 페이지는 CTR -47%로 죽는 중이지만 **인터랙티브 계산기는 AIO가 대체 못 하는 페이지 타입**(Ahrefs 2026 플레이북). 계산기-우선 설계가 곧 방어 전략.

## 4. 경쟁 요약과 포지셔닝 (상세: 마스터 플랜 §3)

| 경쟁자 | 강점 | 약점 → 우리의 기회 |
|---|---|---|
| canirunthisllm.com | 캘리브레이션 방법론, Build Advisor | 모델 22개뿐, SEO 페이지 0, 크라우드 데이터 3건 |
| willitrunai.com | 콤보 URL 선점(394모델×196GPU, 7개 언어) | 추정치 미검증(70B Q2를 4090에서 25 tok/s 주장), 백링크·브랜드 0, thin 페이지 |
| apxml.com | 계산기 브랜드 인지도, 월 34.8만 방문 | 콤보 페이지·크라우드·구매 추천 없음 |
| localscore.ai (Mozilla) | 실측 4,000건, 활발 | 고정 3개 모델만 — 예측 불가. **우리의 캘리브레이션 데이터 소스** |
| hardware-corner.net | 실측 21 GPU×20모델, 어필리에이트 수익화 | 계산기 없음, 영어만 |
| Ollama/LM Studio | 트래픽 소유 | 모델 페이지에 하드웨어 정보 0 = SEO 진공 |

**포지셔닝**: "실측으로 검증된 예측" (Estimates validated against N real benchmarks — 오차 공개) + 이중언어 + 신모델 48h 대응. 정확도·신뢰가 브랜드.
